# PriceHunt · 电商商品价格自动化采集与对比

从京东 / 淘宝 / 拼多多批量采集商品名称、到手价、销量、店铺评分与链接，自动完成清洗去重、跨平台同款对齐、价格排序、性价比评分与趋势分析，输出**命令行结果、CSV、自包含 HTML 报告**，并提供可现场输入关键词运行的**演示网页**。

```
关键词 → 采集 → 清洗 → 归组 → 分析 → 命令行 / 网页 / 报告 / CSV
```

## 快速开始

```bash
cd pricehunt
pip install -r requirements.txt      # 真实采集需要；演示模式仅用标准库

# 1) 跑一次示例（生成 HTML 报告 + CSV）
python3 -m pricehunt demo

# 2) 按关键词采集（默认 auto：实时优先，失败自动降级演示数据）
python3 -m pricehunt search "机械键盘" --platforms jd,tb,pdd --sort value

# 3) 启动演示网页（浏览器打开 http://127.0.0.1:8020）
python3 -m pricehunt serve --port 8020
```

演示网站初始化时会自动用「机械键盘」跑一遍完整链路，作为数据示例与结果示例；输入新关键词会**现场调用后端脚本重新采集**并刷新所有图表。

## 整体架构

```
                    ┌──────────────── CLI（search / demo / serve）
                    │
关键词 ──▶ 调度层 ──┼── source=demo ──▶ 演示数据源（确定性模拟，含噪声）
          collect   │
                    └── source=auto ──▶ 平台适配器（并发）
                                          ├─ 京东：搜索页 + p.3.cn 价格接口
                                          ├─ 淘宝：搜索页 SSR 数据（需登录态）
                                          └─ 拼多多：移动搜索 API（需 anti_content）
                                                    │
                                           全部失败且 auto → 自动降级演示源
                                                    ▼
                                          清洗层 cleaning.py
                                   标准化 → 校验 → 同店去重
                                                    ▼
                                          归组层（型号对齐）
                                  有 model_key 直接用；否则标题相似度聚类
                                                    ▼
                                          分析层 analysis.py
                              异常价剔除 → 性价比评分 → 推荐 → 趋势
                                                    ▼
                    ┌───────────────────────────────┼──────────────────────────┐
               命令行表格                      JSON API（网页）           HTML 报告 / CSV / SQLite 快照
```

| 模块 | 职责 |
| --- | --- |
| `models.py` | 平台元数据、`Listing` 商品条目、`SearchResult` 结果模型 |
| `sources.py` | 三个平台适配器 + 演示数据源 + `auto` 降级调度 |
| `cleaning.py` | 全角转半角、促销词剥离、无效数据校验、同店去重、型号归组、异常价剔除 |
| `analysis.py` | 性价比评分、横向对比分组、四个推荐位、平台胜出统计、趋势序列 |
| `pipeline.py` | 串起全链路，记录各阶段耗时与清洗统计；产物落盘 |
| `report.py` | 生成自包含 HTML 报告（内联 CSS + 手写 SVG 图表） |
| `storage.py` | SQLite 价格快照（支撑真实趋势）、CSV 导出 |
| `webapp.py` | 标准库 HTTP 服务：静态页 + `/api/search` + 报告下载 |
| `cli.py` | `search / demo / serve / platforms` 命令 |

## 数据获取核心逻辑

1. **统一入口**：`collect(keyword, platforms, source)` 统一校验参数、并发调度、汇总各平台警告。
2. **适配器契约**：每个采集器只负责「关键词 → `Listing` 列表」，便于新增平台或替换为官方 API。
3. **并发与超时**：`ThreadPoolExecutor` 同时请求三个平台，单平台超时 8s，整体 12s 内收敛。
4. **真实数据补齐**：京东搜索页价格异步渲染，通过公开价格接口 `p.3.cn/prices/mgets` 批量补齐；淘宝解析页面内嵌商品数据；拼多多调用移动搜索接口。
5. **凭证注入**：`JD_COOKIE` / `TB_COOKIE` / `PDD_COOKIE` 环境变量直接透传到请求头，不写入代码。
6. **自动降级**：远程返回验证页、登录页或接口变化时抛 `SourceError`；`auto` 模式在全部平台失败后切到演示数据源，并在结果中标记 `fallback` 与失败原因，保证工具始终可运行。
7. **演示数据源**：按 `sha256(关键词)` 播种，同一关键词结果稳定可复现；内置跨平台价格差异、平台促销、重复挂牌、9.9 引流价与 30 天价格序列，专门用于验证清洗、对比与趋势链路。

> 当前运行环境实测：京东返回风控校验页、淘宝搜索要求登录、拼多多搜索需要签名，因此网页默认使用演示数据源；配置有效 Cookie 与出口网络后可切到实时采集。

## 数据处理规则

- **标准化**：全角转半角、去促销词（包邮 / 秒杀 / 百亿补贴 / 官方正品等）、压缩空白。
- **校验**：标题非空、价格在 `0.01 ~ 1,000,000`、链接存在。
- **去重**：同平台、同店铺、标题相似度 ≥ 0.92 且价差在 ±20% 内视为重复挂牌，保留最低价。
- **归组**：演示数据直接使用型号键；真实数据按标题二元组 Jaccard 相似度 ≥ 0.55 聚类，实现同款跨平台对齐。
- **异常价剔除**：同型号内价格低于中位数 45% 或高于中位数 280% 的挂牌剔除（引流款、错标价）。
- **排序**：默认按到手价升序，同时支持销量 / 性价比 / 评分排序。

### 性价比指数

```
价格分 = (最高价 - 本价) / (最高价 - 最低价) × 100
销量分 = 对数销量归一化 × 100
评分分 = clip((店铺评分 - 4.0) / 1.0 × 100, 0, 100)   # 缺失时给中性 60
性价比指数 = 价格分 × 45% + 销量分 × 35% + 评分分 × 20%
```

推荐位：**全网最低价 / 性价比之选 / 销量冠军（或热销之选）/ 口碑最佳（或口碑之选）**，优先落到不同型号，避免同款包揽。

## 数据可视化方案

网页与报告共用同一份 JSON 结果：

1. **KPI 概览**：有效报价、覆盖型号、最低价、跨平台最大价差、总销量与平台胜出次数。
2. **商品横向对比**：按型号对齐三平台价格，直接标出最低价与「最多省 ¥X」。
3. **平台最低价命中**：统计各平台成为同型号最低价的次数与平均可省比例。
4. **价格趋势**：型号级近 30 天到手价折线图，带面积渐变、图例、悬停十字线与逐日价格浮层。
5. **价格 × 销量气泡图**：X 轴价格、Y 轴对数销量、气泡大小映射评分、颜色映射平台，点击定位明细。
6. **明细表**：价格 / 销量 / 性价比 / 评分多键排序、平台筛选、名称店铺检索、推荐标签。
7. **HTML 报告**：同一套指标渲染为可打印、可分享的单文件报告（内联 CSS + 服务端 SVG），无需联网。

## 命令行

```bash
python3 -m pricehunt search "空气炸锅" [选项]

  --platforms jd,tb,pdd   指定平台，默认全部
  --source demo|live|auto 数据源，默认 auto
  --limit 40              单平台采集上限
  --sort price|sales|value|rating
  --show 15               终端展示条数
  --json                  输出完整 JSON
  --csv path / --report path
  --no-artifacts          不写默认报告

python3 -m pricehunt demo [关键词] [--out 目录]
python3 -m pricehunt serve [--host 127.0.0.1] [--port 8020] [--open]
python3 -m pricehunt platforms
```

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/search?keyword=机械键盘&platforms=jd,tb,pdd&source=demo&limit=60` | 采集并返回完整 JSON（含 `artifacts` 报告地址） |
| POST | `/api/search` | 同上，JSON 请求体 |
| GET | `/api/health` | 健康检查 |
| GET | `/reports/<file>.html` / `.csv` | 下载本次会话的报告与数据 |
